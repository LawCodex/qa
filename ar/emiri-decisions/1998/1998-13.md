# قرار أميري رقم (13) لسنة 1998 بتشكيل مجلس إدارة المؤسسة العامة لمطار الدوحة الدولي

نحن حمد بن خليفة آل ثاني أمير دولة قطر،

بعد الاطلاع على النظام الأساسي المؤقت المعدل، وبخاصة على المادة (23) منه،

وعلى القانون رقم (17) لسنة 1997 بإنشاء المؤسسة العامة لمطار الدوحة الدولي، وبخاصة على المادة (4) منه،

قررنا ما يلي:

## المواد (1-3)

### مادة 1

يشكل مجلس إدارة المؤسسة العامة لمطار الدوحة الدولي، برئاسة سعادة الشيخ أحمد بن ناصر بن فالح آل ثاني، وزير المواصلات والنقل، وعضوية كل من:

| 1- السيد / سالم بن بطي النعيمي | |

| --- | --- |

| وكيل وزارة المواصلات والنقل | نائباً للرئيس |

| 2- الشيخ / عبد الله بن أحمد بن عبد الله آل ثاني | |

| مدير عام المؤسسة العامة لمطار الدوحة الدولي | عضواً |

| 3- السيد / عبد العزيز محمد النعيمي | |

| مدير إدارة الطيران المدني والأرصاد الجوية | عضواً |

| 4- السيد / غانم عبد الله الخيارين | |

| بوزارة المالية والاقتصاد والتجارة | عضواً |

| 5- المقدم طيار / ناصر عبد الله السليطي | |

| بالقوات المسلحة القطرية | عضواً |

| 6- الرائد / عبد الله علي الجابر الحنزاب المري | |

| بوزارة الداخلية | عضواً |

| 7- السيد / أحمد الباكر | |

| الرئيس التنفيذي لشركة الخطوط الجوية القطرية | عضواً |

### مادة 2

مدة المجلس ثلاث سنوات تبدأ من تاريخ صدور هذا القرار.

### مادة 3

على جميع الجهات المختصة، كل فيما يخصه، تنفيذ هذا القرار. ويعمل به من تاريخ صدوره. وينشر في الجريدة الرسمية.

حمد بن خليفة آل ثاني. — أمير دولة قطر
