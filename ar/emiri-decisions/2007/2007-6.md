# قرار أميري رقم (6) لسنة 2007 بتشكيل اللجنة الوطنية لحقوق الإنسان

نحن حمد بن خليفة آل ثاني أمير دولة قطر،

بعد الإطلاع على الدستور،

وعلى المرسوم بقانون رقم (38) لسنة 2002 بإنشاء اللجنة الوطنية لحقوق الإنسان المعدل بالمرسوم بقانون رقم (25) لسنة 2006،

قررنا ما يلي:

## المواد (1-2)

### مادة 1 معدلة

تشكل اللجنة الوطنية لحقوق الإنسان من كل من:

| 1- الدكتور/ خالد محمد عبدالله العطية. | |

| --- | --- |

| 2- الدكتورة/ نورة خليفة تركي السبيعي. | |

| 3- الدكتور/ يوسف عبيدان فخرو. | |

| 4- الدكتورة/ عائشة يوسف المناعي. | |

| 5- الدكتورة/ حمده حسن السليطي. | |

| 6- الدكتور/ علي سعيد صميخ المري. | |

| 7- الدكتور/ محمد غانم العلي. | |

| 8- الشيخ/ خالد بن جاسم آل ثاني | ممثل وزارة الخارجية. |

| 9- المقدم/ عبد الله صقر المهندي | ممثل وزارة الداخلية. |

| 10- السيد/ عبدالله محمد المريخي | ممثل وزارة شؤون الخدمة المدنية والإسكان. |

| 11- السيد/ سالم راشد المريخي | ممثل وزارة العدل. |

| 12- الآنسة/ نور عبدالله المالكي | ممثل المجلس الأعلى لشؤون الأسرة. |

| السيد/ عيسى سعد الكعبي | |

| السيد/ ناصر عبدالله الحميدي | ممثلاً لوزارة العمل والشؤون الإجتماعية |

وتختار اللجنة في أول اجتماع لها، رئيساً ونائباً للرئيس، من بين أعضائها.

### مادة 2

على جميع الجهات المختصة، كل فيما يخصه، تنفيذ هذا القرار. ويُعمل به من تاريخ صدوره. وينشر في الجريدة الرسمية.

حمد بن خليفة آل ثاني. — أمير دولة قطر
