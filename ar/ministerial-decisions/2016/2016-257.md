# قرار وزير البلدية والبيئة رقم (257) لسنة 2016 بتسمية رئيس وأعضاء لجان فض المنازعات الإيجارية

وزير البلدية والبيئة،

بعد الاطلاع القانون على القانون رقم (4) لسنة 2008 بشأن إيجار العقارات، وتعديلاته،

وعلى قرار مجلس الوزراء رقم (37) لسنة 2008 بشأن القواعد والإجراءات الواجب إتباعها أمام لجان فض المنازعات الإيجارية، وتعديلاته،

وعلى قرار مجلس الوزراء رقم (54) لسنة 2013 بتشكيل لجان فض المنازعات الإيجارية،

وعلى قرار وزير البلدية والتخطيط العمراني رقم (153) لسنة 2016،

قرر ما يلي:

## المواد (1-3)

### مادة 1

"يُسمى رئيس وأعضاء لجان لفض المنازعات الإيجارية الخمسة على النحو التالي:

**اللجنة الأولى:**

| 1- السيد/ عبدالله سعود ياسر المسلم | رئيساً |

| --- | --- |

| 2- السيد/ مبارك سعيد مبارك الهاجري | عضواً |

| 3- السيد/ خليفة أحمد العسيري | عضواً |

**اللجنة الثانية:**

| 1- السيد/ عايض سعد سعيد القحطاني | رئيساً |

| --- | --- |

| 2- السيد/ علي محمد حسن الحمادي | عضواً |

| 3- السيد/ محمد حمد جابر المري | عضواً |

**اللجنة الثالثة:**

| 1- السيد/ محمد علي حمد العذبي | رئيساً |

| --- | --- |

| 2- السيد/ ناصر حمد الجبارة | عضواً |

| 3- السيد/ حمد عبدالله حسن | عضواً |

**اللجنة الرابعة:**

| 1- السيد/ ناصر أحمد السعدي | رئيساً |

| --- | --- |

| 2- السيد/ فهد خاطر السليطي | عضواً |

| 3- السيد/ منصور فرج القحطاني | عضواً |

**اللجنة الخامسة:**

| 1- السيد/ حمد وديع محمود الطويل | رئيساً |

| --- | --- |

| 2- السيد/ محمد مشعل الهاجري | عضواً |

| 3- السيد/ نوف عبدالرحمن المالكي | عضواً |

### مادة 2

يُلغى كل حكم يخالف أحكام هذا القرار.

### مادة 3

على جميع الجهات المختصة، كل فيما يخصه، تنفيذ هذا القرار، ويُعمل به من تاريخ 01/10/2016 وينشر في الجريدة الرسمية.

محمد بن عبدالله الرميحي — وزير البلدية والبيئة
