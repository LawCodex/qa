# قرار وزير البلدية والتخطيط العمراني رقم (153) لسنة 2015 بتسمية رئيس وأعضاء لجان فض المنازعات الإيجارية

وزير البلدية والتخطيط العمراني،

بعد الاطلاع القانون على القانون رقم (4) لسنة 2008 بشأن إيجار العقارات، وتعديلاته،

وعلى قرار مجلس الوزراء رقم (37) لسنة 2008 بشأن القواعد والإجراءات الواجب إتباعها أمام لجان فض المنازعات الإيجارية، وتعديلاته،

وعلى قرار مجلس الوزراء رقم (54) لسنة 2013 بتشكيل لجان فض المنازعات الإيجارية،

قرر ما يلي:

## المواد (1-3)

### مادة 1

"يُسمى رئيس وأعضاء لجان لفض المنازعات الإيجارية الخمسة على النحو التالي:

اللجنة الأولى:

| 1- السيد/ عبدالله سعود ياسر المسلم | رئيساً |

| --- | --- |

| 2- السيد/ مبارك سعيد مبارك حليمان الهاجري | عضواً |

| 3- السيد/ علي خميس سعد الكبيسي | عضواً |

اللجنة الثانية:

| 1- السيد/ عايض سعد سعيد القحطاني | رئيساً |

| --- | --- |

| 2- السيد/ علي محمد حسين الحمادي | عضواً |

| 3- السيد/ محمد حمد جابر المري | عضواً |

اللجنة الثالثة:

| 1- السيد/ محمد علي حمد العذبي | رئيساً |

| --- | --- |

| 2- السيد/ حمد محمد متعب الصعاق | عضواً |

| 3- السيد/ حمد عبدالله حسن | عضواً |

اللجنة الرابعة:

| 1- السيد/ غانم ثامر ناصر الحميدي | رئيساً |

| --- | --- |

| 2- السيد/ فهد خاطر السليطي | عضواً |

| 3- السيد/ ناصر سعيد حمد هادي | عضواً |

اللجنة الخامسة:

| 1- السيد/ حمد وديع محمود الطويل | رئيساً |

| --- | --- |

| 2- السيد/ راشد حسين راشد الحسين | عضواً |

| 3- السيد/ مبارك سالم سعيد النابت | عضواً |

### مادة 2

يُلغى كل حكم يخالف أحكام هذا القرار.

### مادة 3

على جميع الجهات المختصة، كل فيما يخصه، تنفيذ هذا القرار، ويُعمل به من تاريخ صدوره وينشر في الجريدة الرسمية.

عبدالرحمن بن خليفة آل ثاني — وزير البلدية والتخطيط العمراني
