# قرار وزير الاقتصاد والتجارة رقم (35) لسنة 2003 بشأن تأسيس شركة «الوطنية للإجارة» «شركة مساهمة قطرية»

وزير الاقتصاد والتجارة،

بعد الاطلاع على النظام الأساسي المؤقت المعدل، وبخاصة على المادتين (23)، (24) منه

وعلى القانون رقم (5) لسنة 2002 بإصدار قانون الشركات التجارية،

وعلى القانون رقم (12) لسنة 1989 بشأن القواعد الموحدة لتملك مواطني دول مجلس التعاون لدول الخليج العربية أسهم شركات المساهمة ونقل ملكيتها، وتعديلاته،

وعلى عقد تأسيس شركة الوطنية للإجارة (شركة مساهمة قطرية) ونظامها الأساسي المصدق عليهما بمحضري التوثيق رقم (1658) ورقم (1767) بتاريخ 21/4/2003،

وعلى إقتراح الوكيل المساعد،

قرر ما يلي:

## المواد (1-3)

### مادة 1

يُرخص لكل من:

| 1- | شركة المشاريع الخاصة | قطرية |

| --- | --- | --- |

| 2- | شركة المستثمر الدولي | قطرية |

| 3- | شركة الخليج لتسويق الأعمال | قطرية |

| 4- | شركة المجال الدولي للتجارة والمقاولات | قطرية |

| 5- | الشركة الدولية للتوكيلات المحدودة | قطرية |

| 6- | الشركة الدولية للإستثمارات المالية | قطرية |

| 7- | بيت الإستثمار | قطرية |

| 8- | شركة قطر للإستثمار وتطوير المشاريع | قطرية |

| 9- | شركة قطر الوطنية لصناعات الأسمنت | قطرية |

| 10- | شركة قطر الوطنية للملاحة والنقليات المحدودة | قطرية |

| 11- | بنك الدوحة | قطرية |

| 12- | شركة الخليج للتأمين | قطرية |

| 13- | الشركة القطرية للصناعات التحويلية | قطرية |

| 14- | الشركة القطرية للنقل البحري | قطرية |

| 15- | سليمان بن أحمد الحوقني | عُماني |

| 16- | شركة الحق للتجارة والمقاولات | قطرية |

| 17- | مركز التموين العائلي | قطرية |

| 18- | مؤسسة قطر للتربية والعلوم والتنمية وتنمية المجتمع | قطرية |

| 19- | الشركة القطرية للإستثمارات العقارية | قطرية |

| 20- | شركة البيداء للنقليات | قطرية |

| 21- | الشركة القطرية الإستثمارية للسيدات | قطرية |

| 22- | بنك قطر الدولي الإسلامي | قطرية |

| 23- | الشركة الإسلامية القطرية للتأمين | قطرية |

| 24- | شركة قطر للنقليات السريعة | قطرية |

| 25- | الشركة العربية للنقل البري | قطرية |

بتأسيس شركة مساهمة قطرية تسمى شركة "الوطنية للإجارة" برأس مال مدفوع قدره (150,000,000 ريال).

### مادة 2

على المؤسسين الإلتزام بأحكام عقد تأسيس الشركة ونظامها الأساسي، والإلتزام بأحكام قانون الشركات التجارية المشار إليه، والقوانين الأخرى المعمول بها.

### مادة 3

على جميع الجهات المختصة، كل فيما يخصه، تنفيذ هذا القرار. وينشر في الجريدة الرسمية.

حمد بن فيصل بن ثاني آل ثاني — وزير الإقتصاد والتجارة
