# قرار مجلس الوزراء رقم (42) لسنة 2009 بتعديل بعض أحكام القرار رقم (36) لسنة 2008 بتشكيل لجان فض المنازعات الإيجارية

مجلس الوزراء،

بعد الاطلاع على الدستور،

وعلى القانون رقم (4) لسنة 2008 بشأن إيجار العقارات، المعدل بالقانون رقم (20) لسنة 2009،

وعلى القرار الأميري رقم (29) لسنة 1996 بشأن قرارات مجلس الوزراء التي ترفع للأمير للتصديق عليها وإصدارها،

وعلى قرار مجلس الوزراء رقم (36) لسنة 2008 بتشكيل لجان فض المنازعات الإيجارية،

وعلى اقتراح وزير البلدية والتخطيط العمراني،

قرر ما يلي:

## المواد (1-2)

### مادة 1

يُستبدل بنص المادة (1) من قرار مجلس الوزراء رقم (36) لسنة 2008 المشار إليه، النص التالي :

مادة (1):

«تُشكل في وزارة البلدية والتخطيط العمراني أربع لجان لفض المنازعات الإيجارية، على النحو التالي :

| 1ـ اللجنة الأولى : | |

| --- | --- |

| 1ـ السيد/ نبيل محضار السعدي | رئيساً |

| 2ـ السيدة/ نوف عبد الرحمن عبد الله المالكي | عضواً |

| 3ـ السيد/ نبيل محمد أحمد بدر | عضواً |

| 2ـ اللجنة الثانية : | |

| 1ـ السيد/ خالد محمد آل شريم | رئيساً |

| 2ـ السيد/ جاسم عبدالله طالب المحنا | عضواً |

| 3ـ السيد/ علي محمد حسين الحمادي | عضواً |

| 3ـ اللجنة الثالثة : | |

| 1ـ السيد/ علي خميس السليطي | رئيساً |

| 2ـ السيد/ ناصر محمد سعيد الجبارة | عضواً |

| 3ـ السيد/ حمد محمد متعب الصعاق | عضواً |

| 4ـ اللجنة الرابعة : | |

| 1ـ السيد/ ناصر عيسى الخليفي | رئيساً |

| 2ـ السيد/ سعيد نفل سعيد الدوسري | عضواً |

| 3ـ السيد/ مبارك سالم سعيد النابت | عضواً |

### مادة 2

على جميع الجهات المختصة، كل فيما يخصه، تنفيذ هذا القرار. ويعمل به من تاريخ صدوره. وينشر في الجريدة الرسمية.

حمد بن جاسم بن جبر آل ثاني, حمد بن خليفة آل ثاني — رئيس مجلس الوزراء, أمير دولة قطر
