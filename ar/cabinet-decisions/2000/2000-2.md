# قرار مجلس الوزراء رقم (2) لسنة 2000 بتشكيل لجنة شئون الحج

مجلس الوزراء،

بعد الاطلاع على النظام الأساسي المؤقت المعدل، وبخاصة على المادتين (33)، (34) منه،

وعلى القانون رقم (6) لسنة 1993 بشأن تنظيم شئون الحج، وبخاصة على المادة (2) منه،

وعلى القانون رقم (9) لسنة 1993 بتنظيم وزارة الأوقاف والشئون الإسلامية وتعيين اختصاصاتها،

وعلى القرار الأميري رقم (29) لسنة 1996 بشأن قرارات مجلس الوزراء التي تُرفع للأمير للتصديق عليها وإصدارها،

وعلى قرار مجلس الوزراء رقم (7) لسنة 1997 بإعادة تشكيل لجنة شئون الحج،

وعلى اقتراح وزير الأوقاف والشئون الإسلامية،

قرر ما يلي:

## المواد (1-3)

### مادة 1 معدلة

تشكل لجنة شئون الحج على النحو التالي:

| 1- السيد / عبد الرحمن بن عبد الله آل محمود | رئيساً |

| --- | --- |

| 2- السيد / محمد بن عبد اللطيف المانع | نائباً للرئيس |

| 3- السيد / عبد العزيز بن علي الحمادي | |

| ممثلاً لوزارة الأوقاف والشئون الإسلامية | عضواً |

| 4- المقدم / سالم علي النعيمي | |

| ممثلاً لوزارة الداخلية | عضواً |

| 5- الدكتور / عيسى مبارك حجي السليطي | |

| ممثلاً لوزارة الصحة العامة | عضواً |

| 6- السيد /علي أحمد المحمود | |

| ممثلاً لوزارة الخارجية | عضواً |

| 7- السيد / يوسف عبد الرحمن الملا | |

| ممثلاً لوزارة التربية والتعليم والتعليم العالي | عضواً |

| 8- الشيخ / فيصل بن جاسم آل ثاني | |

| ممثلاً للهيئة العامة للإذاعة والتليفزيون | عضواً |

| 9- السيد / يوسف محمد المفتاح | |

| ممثلاً لجمعية الهلال الأحمر القطري | عضواً |

ويحل نائب الرئيس محل الرئيس في حالة غيابه، أو خلو منصبه.

### مادة 1 (مكرر 1)

يكون للجنة مقرر، يَصدر بندبه وتحديد مكافأته، قرار من وزير الأوقاف والشؤون الإسلامية.

### مادة 2

يُلغى قرار مجلس الوزراء رقم (7) لسنة 1997 المشار إليه.

### مادة 3

على جميع الجهات المختصة، كل فيما يخصه، تنفيذ هـذا القرار. ويُعمل به من 14/2/2000. ويُنشر في الجريدة الرسمية.

عبد الله بن خليفة آل ثاني, حمد بن خليفة آل ثاني — رئيس مجلس الوزراء, أمير دولة قطر
