# أمر أميري رقم (2) لسنة 1995 بإعادة تشكيل مجلس الوزراء

نحن حمد بن خليفة ال ثاني أمير دولة قطر،

بعد الاطلاع على النظام الأساسي المؤقت المعدل، وبخاصة على المواد (23)، (29)، (31) منه،

وعلى القانون رقم (5) لسنة 1970 بتحديد صلاحيات الوزراء، وتعيين اختصاصات الوزارات والأجهزة الحكومية الأخرى، والقوانين المعدلة له،

وعلى الأمر الأميري رقم (1) لسنة 1992 بإعادة تشكيل مجلس الوزراء،

أمرنا بما يأتي:

## المواد (1-3)

### مادة 1

يعاد تشكيل مجلس الوزراء برئاستنا، على النحو التالي مع احتفاظنا بمنصبي وزير الدفاع والقائد العام للقوات المسلحة:

| 1- سمو الشيخ/ عبدالله بن خليفة آل ثاني | - نائباً لرئيس مجلس الوزراء ووزيراً للداخلية. |

| --- | --- |

| 2- سعادة الشيخ/ حمد بن سحيم ال ثاني | - وزيراً للدولة بالديوان الأميري. |

| 3- سعادة الشيخ/ محمد بن خليفة آل ثاني | - وزيراً للمالية والاقتصاد والتجارة. |

| 4- سعادة الشيخ/ حمد بن جاسم بن جبر آل ثاني | - وزيراً للخارجية. |

| 5- سعادة الشيخ/ أحمد بن سيف آل ثاني | - وزيراً للدولة. |

| 6- سعادة الشيخ/ حمد بن عبدالله آل ثاني | - وزيراً للدولة لشؤون الدفاع، عضواً في مجلس الوزراء، ونائباً للقائد العام للقوات المسلحة. |

| 7- سعادة الشيخ/ عبدالله بن خالد ال ثاني | - وزيراً للأوقاف والشؤون الإسلامية. |

| 8- سعادة الشيخ/ أحمد بن حمد آل ثاني | - وزيراً للشؤون البلدية والزراعة. |

| 9- سعادة الشيخ/ محمد بن خالد آل ثاني | - وزيراً للدولة لشؤون مجلس الوزراء وعضواً في مجلس الوزراء. |

| 10- سعادة السيد/ عبدالله صالح المانع | - وزيراً للمواصلات والنقل. |

| 11- سعادة السيد/ عبد العزيز عبدالله تركي | - وزيراً للتربية والتعليم. |

| 12- سعادة السيد/ أحمد محمد علي السبيعي | - وزيراً للكهرباء والماء. |

| 13- سعادة السيد/ عبدالله حمد العطية | - وزيراً للطاقة والصناعة. |

| 14- سعادة الدكتور/ حمد عبد العزيز الكواري | - وزيراً للإعلام والثقافة. |

| 15- سعادة السيد/ علي سعيد الخيارين | - وزيراً للصحة العامة. |

| 16- سعادة الدكتور/ نجيب محمد النعيمي | - وزيراً للعدل. |

| 17- سعادة السيد/ أحمد عبدالله آل محمود | - وزيراً للدولة للشؤون الخارجية. |

### مادة 2

يلغى الأمر الأميري رقم (1) لسنة 1992 المشار إليه، والمراسيم والأوامر الأميرية المعدلة والمكملة له، كما يلغى كل حكم يخالف أحكام هذا الأمر الأميري.

### مادة 3

يعمل بهذا الأمر الأميري من تاريح صدوره. وينشر في الجريدة الرسمية.

حمد بن خليفة آل ثاني. — أمير دولة قطر
