# قرار رقم (72) لسنة 2022 بتخويل بعض موظفي المؤسسة العامة القطرية للكهرباء والماء صفة مأموري الضبط القضائي

النائب العام،

بعد الاطلاع على القانون رقم (11) لسنة 1979 بشأن حماية المنشآت الكهربائية والمائية العامة،

وعلى القانون رقم (23) لسنة 2004 بإصدار قانون الإجراءات الجنائية والقوانين المُعدلة له وبخاصة على المادة (27) منه،

وعلى اقتراح وزير الدولة لشؤون الطاقة،

قرر الآتي:

## المواد (1-2)

### مادة 1

يكون لموظفي المؤسسة العامة القطرية للكهرباء والماء التالية أسماؤهم صفة مأموري الضبط القضائي في ضبط وإثبات الجرائم التي تقع بالمخالفة لأحكام القانون رقم (11) لسنة 1979 المُشار إليه، والقرارات المنفذة له وهم:

| **م** | **الإسم** | **المسمى الوظيفي** |

| --- | --- | --- |

| | حمد سالم صالح الكاموخة المري | محلل تخطيط |

| | عبدالعزيز عبدالرحمن حاجي محمد الشرشني | مفتش ميداني |

| | ناصر عبدالله سعيد العلي | مشرف محطة |

| | خليل إبراهيم عبدالرحمن يوسف المالكي | مشرف محطة |

| | فرج علي فرج الغفراني المري | مشرف محطة |

| | حصين جابر علي الزيدان المري | مفتش ميداني |

| | عبد الله سالم جمعة بشيت المنصوري | مشرف محطة |

| | خالد محمد بخيت البكر الكواري | مشرف محطة |

| | حمد محمد حمد الزبدان المري | مفتش ميداني |

### مادة 2

على جميع الجهات المختصة كل فيما يخُصه، تنفيذ هذا القرار، ويُعمل به من تاريخ صدوره، ويُنشر في الجريدة الرسمية

د. عيسى بن سعد الجفالي النعيمي — النائب العام
